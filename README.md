
# os_init 
我们的想法当Linux 开发者在是对系统的有了足够的熟悉的情况下
1. 可以一键设置对应的需求
2. 默认可以自动修改系统配置方便使用
3. 针对windows vmware、virtualbox 等虚拟机，使用的VMimage等镜像快速使用，保证环境的快速创建。
## 支持的脚本
- 镜像脚本修改：[VMimage](https://www.linuxvmimages.com/)
- 镜像脚本修改：[osboxes](https://www.osboxes.org/virtualbox-images/)
