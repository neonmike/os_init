
# os_init 
我们的想法当Linux 开发者在是对系统的有了足够的熟悉的情况下
可以一键设置对应的需求
默认可以自动修改系统配置方便使用

针对windows vmware、virtualbox 等虚拟机，使用的VMimage等镜像快速使用，保证环境的快速创建。

## 功能
初始化以下内容
- 设置的History 记录、长线保持
- 修改root 密码：neon
- 修改软件源 ：阿里镜像仓库地址
- 下载默认代理工具：clash for linux install
